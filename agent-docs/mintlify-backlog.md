# Mintlify docs backlog

The public Mintlify docs site is parked until the domain choice locks. Every PR that ships a user-facing surface (CLI command, MCP tool, TUI screen, config knob, env var, error code) appends an entry below so the docs are ready when Mintlify lights up.

AGENTS.md rule 11 enforces the discipline. When Mintlify activates (target: M2), `@docs-writer` walks this file top to bottom and drafts the pages.

## Entry format

```
| Path | Source(s) | Status | Description | Updated |
|---|---|---|---|---|
| `docs/cli/maz-daemon.mdx` | #42 (daemon supervisor) | backlog | `maz daemon start/stop/status/logs` reference | 2026-05-23 |
```

- **Path**: intended Mintlify page path under `docs/`. **The path must match a leaf in `docs/docs.json` `navigation.tabs[].groups[].pages`.** If the page is new, the PR also adds it to the matching `groups[].pages` array. The current nav has five groups: "Get started" (`introduction`, `quickstart`), "Tutorials" (`tutorials/index`), "How-to guides" (`how-to/index`), "Reference" (`reference/index`, `reference/cli`), "Explanation" (`explanation/index`, `explanation/architecture`).
- **Source(s)**: PR(s) and issue(s) that produced the user-facing surface.
- **Status**: `backlog` (queued), `drafted` (page exists, awaiting review), `published` (live on Mintlify).
- **Description**: one short sentence; what the page covers.
- **Updated**: last edit to this row (YYYY-MM-DD).

Order rows by intended path (Diataxis section, then alphabetical).
