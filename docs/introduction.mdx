Mazarbul is an agent system of record. A single local-first binary that gives every agent a place to remember, recall, and reason about your scattered context: chats, code, emails, documents, decisions. Provenance on every fact. Local SQLite + Kuzu + sqlite-vec + FTS5 storage. MCP as the primary surface so any agent can connect.
